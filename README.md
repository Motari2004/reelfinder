# Reels Finder API

Search and extract Instagram Reel URLs using the ReelsFinder website.

## Live Demo
- **API**: https://reels-finder.onrender.com
- **Search**: https://reels-finder.onrender.com/search?q=nature

## Features
- Search Instagram Reels by hashtag or keyword
- Extract URLs with metadata (username, caption, likes, comments)
- Fast API with JSON responses
- Web interface for testing
